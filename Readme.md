# Desafio: Construindo um modelo de Regressão para marketing
Este projeto foi criado com o intuito de aprimorar habilidades em Python utilizando um modelo de Regressão. O objetivo neste projeto é feio a análise de dados. Além disso é criado um modelo de predição de valores para estimar o retorno de vendas que pode ser gerado a partir de um determinado investimento em publicidade.

Portanto separei este projeto em 4 partes : 

# Análise Descritiva

Consiste em explorar os dados do dataset para compreender melhor as variáveis e identificar problemas. Para isso foi utilizado a biblioteca
Pandas para importar e manipular os dados e realizar cálculos estatísticos, além das bibliotecas de visualização.

#  Análise Exploratória

Nesta etapa vamos identificar relações entre as variáveis e descobrindo padrões relevantes. Para isso, utilizei técnicas de visualização de dados e análises estatísticas, buscando possíveis correlações e
identificando possíveis outliers ou desvios da normalidade.

# Modelagem

Construi um modelo simples de regressão que permita a previsão solicitada pela empresa, com base nos dados disponíveis. Para isto, carreguei os conjuntos de dados para iniciar a minha construção. 
Ultilizei um modelo de regressão simples utilizando a biblioteca sklearn.

# Calculando predição

E por fim apliquei o modelo de regressão construído nas etapas anteriores para realizar as previsões de retorno de vendas que podem ser gerado a partir de um determinado investimento em publicidade.
Através dessas previsões, poderemos avaliar o impacto dos diferentes níveis de investimento em marketing nas vendas, auxiliando na tomada de decisões e na definição de estratégias de negócio.
